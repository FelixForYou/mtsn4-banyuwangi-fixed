# MTsN 4 Banyuwangi — Vercel Deployment

Paket ini sudah diperbaiki agar `index.html` berada di ROOT project.

## Deploy ke Vercel
1. Upload/extract isi ZIP ini sebagai **root project**.
2. Pastikan struktur awal project terlihat seperti:
   - `index.html`
   - `css/`
   - `js/`
   - `data/`
   - `pages/`
   - `assets/`
   - `vercel.json`
3. Framework Preset: **Other** / Static.
4. Build Command: **kosongkan**.
5. Output Directory: **kosongkan** (atau `.` jika diminta).
6. Deploy.

Jangan upload folder pembungkus `mtsn4-banyuwangi/` sebagai satu folder di dalam project. ZIP ini sudah tidak memakai folder pembungkus tersebut.
